# 📖 Bibles XML - JoBlessM Edition

Bienvenue sur le dépôt **Bibles-Xml**. Ce projet met à disposition des versions complètes de la Bible au format standard **Zefania XML**, spécialement nettoyées, structurées et optimisées pour une utilisation fluide avec les **docks OBS Studio**, **OpenLP**, et autres outils de projection en direct pour les cultes et diffusions live.

---

## 🎯 Caractéristiques

- 🧼 **Texte 100 % pur** : Suppression des numéros Strong et codes techniques parasites pour un affichage direct propre.
- 🇫🇷 **Typographie soignée** : Respect intégral des accents, espaces et ponctuations françaises.
- ⚡ **Compatibilité maximale** : Format Zefania XML (`<BIBLEBOOK>`, `<CHAPTER>`, `<VERS>`) reconnu universellement par les docks OBS et logiciels chrétiens.
- 📦 **Canon complet** : 66 livres, 1 189 chapitres, 31 168 versets sans omission.

## 🚀 Utilisation dans OBS Studio

1. Téléchargez le fichier `.xml` de la version souhaitée.
2. Dans votre **Dock OBS Bible**, sélectionnez le fichier XML téléchargé.
3. Recherchez vos livres, chapitres et versets pour les projeter en direct sur votre stream !
